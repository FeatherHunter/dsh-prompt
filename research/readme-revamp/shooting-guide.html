8 张分镜：场景 + 步骤（拍完打勾）

01 · assets/readme/01-install-ready.png · 宽度 720

场景：安装就绪。一条干净的新会话，输入框左侧可见 ⚡Prompt 按钮（源码 src/client/button.ts：输入框左侧入口，hover 即开、click 兜底）。

步骤：① 新开 DSH Web 会话，不输入任何字；② 确认输入框左侧有“⚡Prompt”按钮；③ 截输入框整条横幅（含按钮 + 空输入框 + 发送键），停在未展开面板的一屏。

02 · assets/readme/02-panel-button.png · 宽度 640

场景：入口一 · Prompt 按钮悬浮面板。模板浏览浮层（阶段 tabs 执行前/中/后 + 领域筛选 + 搜索；bottom-up：最常用沉底，置顶簇在底部）。

步骤：① 鼠标移到输入框左侧 ⚡Prompt 按钮（或单击），等悬浮面板展开；② 停在“全部 tabs + 若干模板行（图钉 + 标题 + 简介 + hover 操作）”首屏；③ 截面板完整浮层（含背后的输入框按钮锚点）。

03 · assets/readme/03-trigger-prompt.png · 宽度 640

场景：入口二 · /prompt 触发源。在输入框输 /prompt 弹出候选（行格式“名称 + 标签·阶段 — 正文前42字”，支持 /prompt 复盘 按词过滤）。

步骤：① 输入框输 /prompt（半角斜杠），等候选列表弹出；② 再输 /prompt 复盘 展示过滤后行；③ 截“输入框内 /prompt 复盘 + 下方候选列表 3~5 行”。

⛔ 04 · assets/readme/04-smart-card.png · 已砍掉（节保留纯文字版，不拍）

场景：入口三 · 智能悬浮卡。输入命中时自动出卡（专属词×2 + 通用词×1，≥2 分出卡，≤3 候选；卡 280px 从圆点向右展开，可拖动）。

步骤：① 新会话输入框逐字输入 这次任务做砸了，我想复盘一下，总结可复用经验（命中 retro 强词“复盘 / 可复用经验”，必出卡）；② 等悬浮卡展开（默认开；若无卡先检查设置页智能开关）；③ 截“输入框文字 + 右侧展开的候选卡（2~3 行）”。备选触发句：两个选项很纠结，有沉没成本，帮我决策。

05 · assets/readme/05-templates-gallery.png · 宽度 640

场景：模板一览。24 条预制全貌（思考框架 / 学习 / 工程 / 执行 × 执行前 / 中 / 后）。

步骤：① DSH 设置 → 插件 → dsh-prompt 设置页；② 停在“阶段 tabs + 领域筛选 + 模板行铺满”首屏；③ 截设置页模板区完整一屏。

06 · assets/readme/06-custom-manage.png · 宽度 640

场景：自定义管理。新增 / 编辑弹窗 + 删除二次确认 + 置顶（≤5）+ 预制复制为自定义。

步骤：① 设置页点“＋新增”，弹窗填标题 我的复盘模板、正文 请复盘：主题：，截弹窗；② hover 某行出现图钉 / 编辑 / 删除，点删除截二次确认框；③ 可二合一拼图（左弹窗右确认框）。

⛔ 07 · assets/readme/07-privacy-smart-toggle.png · 已砍掉（并入设置节一句话，不拍）

场景：隐私 + 智能开关。设置页顶部（仓库链接行 + “智能模式悬浮卡（输入匹配时推荐模板；默认开）”勾选行）+ 隐私节文字对照（本地存储、无上报）。

步骤：① 设置页顶部，截“仓库 / 反馈链接行 + 智能开关勾选行”；② 同屏带出 1~2 行模板区以示位置；③ 隐私节正文写“模板与用量存本地浏览器、无网络上报”，本图即配图。

⛔ 08 · assets/readme/08-faq-reinstall.png · 已砍掉（FAQ 用命令代码块，不拍）

场景：FAQ。更新不生效 → 官方源重装回显（对标参考 08 图）。

步骤：① 终端执行 dsh plugin --profile web add dsh-prompt@latest --registry https://registry.npmjs.org；② 等成功回显；③ 截“命令 + 成功回显”完整终端区。desktop 用户把 --profile web 换成 --profile desktop（FAQ 注明）。
